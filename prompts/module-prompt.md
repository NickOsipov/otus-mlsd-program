# Промпт для подготовки занятий (модули 1-3)

Для каждого занятия модуля составь:

**1. Цели занятия**
Начинай каждую цель с глагола (использовать, применять, выбирать, анализировать, разрабатывать, оценивать и т.д.). Формулируй как навык, который студент сможет применять в профессиональной деятельности после занятия — не тему лекции, а действие. Каждая цель — с новой строки, со строчной буквы, в конце точка с запятой. Без нумерации. 3 цели на занятие.

**2. Краткое содержание**
Список технологий/понятий/процессов, которые разбираются на занятии — по пунктам темы из программы курса. Каждый пункт с новой строки, со строчной буквы, точка с запятой в конце. Без нумерации, без вводных фраз.

**3. Результат**
Конкретный артефакт, который студент создаёт или получает на занятии: раздел design doc, диаграмма, расчёт, шаблон, код. Если занятие теоретическое без практического артефакта — писать "конспект лекции". Для занятий, где есть ДЗ или чекпоинт сразу после — результат должен согласовываться с тем, что сдаётся.

**Правила согласованности:**
- цели, содержание и результат одного занятия должны логически соответствовать друг другу — результат вытекает из целей, содержание объясняет, за счёт чего цели достигаются
- если после занятия есть чекпоинт или ДЗ — результат занятия и есть черновик/часть этого чекпоинта/ДЗ
- не дублировать формулировки между соседними занятиями модуля — если есть содержательное пересечение (как было с 3.1/3.2), заранее развести акценты
- сверяться с финальной программой курса и списком ДЗ (4 накопительных ДЗ и итоговый проект), чтобы результаты занятий стыковались с ближайшей сдачей или проектом

**Формат вывода:** по каждому занятию — заголовок (номер и название), затем три блока: Цели занятия / Краткое содержание / Результат, как в примерах по Модулю 1.
