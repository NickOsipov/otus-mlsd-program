# Шаблон заполнения ДЗ в паспорте курса лист: Программа

ВАЖНОЕ! Домашнее задание ОБЯЗАТЕЛЬНО привязывается к конкретному занятию.

В домашнем задании есть три основных раздела:
1. Название ДЗ
2. Компетенции по ДЗ
3. Навык по ДЗ

Название ДЗ

Оптимальное количество ДЗ в курсе высчитывается по формуле: кол-во уроков : кол-во ДЗ = 3

Здесь пишем названия будущих ДЗ. Пошаговая инструкция к ДЗ создаёться во вкладке 4.1 ДЗ.

Компетенции по ДЗ

Вы уже знаете, что компетенция - это способность успешно действовать на основе практического опыта, умения и знаний при решении профессиональных задач. В ДЗ студенты тоже самостоятельно решают одну или несколько задач, их здесь и прописываем.

Для каждого ДЗ необходимо указать соответствующую компетенцию. Они могут совпадать с компетенцией и навыком урока, включать в себя несколько компетенций и навыков из модуля или быть новыми, ранее не указанными.

Навык по ДЗ

Как ранее говорилось, компетенция складывается из Знаний, Умений и Навыков (ЗУН). 

Знания - понимание, сохранение в памяти и умение воспроизводить факты науки и вытекающие из них теоретические обобщения (правила, законы, выводы и т.д.)
Навыки - действие, доведенное до автоматизма путем многократных повторений. Пробовал много раз, могу делать без помощи.
Умения - способность делать что-либо, приобретённое знанием, опытом.

Для каждого ДЗ необходимо указать соответствующие ЗУНы. Они могут совпадать с ЗУНами урока, включать в себя несколько навыков из модуля или быть новыми, ранее не указанными.

Например,
Компетенция: работать с гитхабом 
Умение: создавать организации, репозитории
