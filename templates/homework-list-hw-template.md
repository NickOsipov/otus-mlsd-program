Структура

В какое занятие поместить ДЗ - Название занятия, где должно находиться ДЗ

Название Название ДЗ (в нём можно коротко описать процесс, который лежит в основе задания)

Цель и результат ДЗ - Что студенту нужно сделать в ДЗ и какой результат должен получиться
"Подробное описание последовательность шагов, которые нужно сделать студенту для выполнения ДЗ. Решение задачи студент ищет самостоятельно, важно дать ему для этого все необходимые критерии и инструменты 

Описание/ Пошаговая инструкция выполнения ДЗ -Подробное описание последовательность шагов, которые нужно сделать студенту для выполнения ДЗ. Решение задачи студент ищет самостоятельно, важно дать ему для этого все необходимые критерии и инструменты 

Формат сдачи - В каком виде необходимо сдать ДЗ на проверку. Перечисление форматов, типов и количества артефактов, которые должны быть созданы 

Критерии оценки - На что, в первую очередь, обратит внимание проверяющий преподаватель. Здесь можно указать самые важные пункты из задания, конкретные действия, артефакты или же следующие критерии:

1. Обоснованность
2. Работоспособность
3. Качество
4. Полнота выполнения
5. Креативность

Для оценки можно используется система:

1. Статусы ""Принято"" \ ""Возвращено на доработку"", без указания баллов

Компетенция - Навык - "Какие скиллы развиваются в этом ДЗ. Внести сюда то, что было ранее указано во вкладке 4. Программа, в столбцах с компетенциями и навыками
"

Материалы для ДЗ

Какие доп.материалы нужно предоставить студентам для выполнения ДЗ. Например: ноутбук, база данных, ссылка на репо, код, какой-либо документ. Дать ссылку на готовый материал с открытым доступом (или указываем, что подгружен к платформе).


Примечание для преподавателя
"Шаблон для ответа на ДЗ студенту с критериями и поддерживающей обратной связью.

Сюда по необходимости можно внести готовый ответ на ДЗ или важную информацию для проверяющего"
