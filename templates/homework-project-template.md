# Шаблон заполнения в паспорте курса лист: Проект


## Разделы для заполнения:
Название - Название темы проектной работы, цель проектной работы.
Цель проекта - Что нужно сделать в проектной работе, смысл проектной работе, применение.
Описание проекта / Техническое задание - Пошаговая инструкция, что нужно сделать с подробным описанием шагов.

Есть каждый студент сам выбирает для себя тему проекта и единой инструкции нет, то нужно прописать, как тему утвердить и дать общие рекомендации по созданию проекта.
Форма сдачи - В каком виде происходит сдача проекта, что нужно подготовить для защиты.
Критерии оценки - Основные условия, которые должны выполнить студент для получения положительной аттестации.
Список тем (не менее пяти, если нет общей) - Если нет единого задания, то нужно прописать не менее пяти тем, из которых студенты могут выбрать одну для своей проектной работы.
Материалы для проекта - Какие доп.материалы нужно предоставить студентам для выполнения проектной работы. Например: ноутбук, база данных, ссылка на репо, код, какой-либо документ. Дать ссылку на готовый материал с открытым доступом (или указываем, что подгружен к платформе).
Рекомендации к выполнению - Рекомендации ПО
Список рекомендованных источников - Список рекомендованных источников
