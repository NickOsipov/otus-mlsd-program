# Промпт для подготовки занятий (модули 1-3)

Для каждого занятия модуля составь:

**1. Цели занятия**
Начинай каждую цель с глагола (использовать, применять, выбирать, анализировать, разрабатывать, оценивать и т.д.). Формулируй как навык, который студент сможет применять в профессиональной деятельности после занятия — не тему лекции, а действие. Каждая цель — с новой строки, со строчной буквы, в конце точка с запятой. Без нумерации. 3 цели на занятие.

**2. Краткое содержание**
Список технологий/понятий/процессов, которые разбираются на занятии — по пунктам темы из программы курса. Каждый пункт с новой строки, со строчной буквы, точка с запятой в конце. Без нумерации, без вводных фраз.

**3. Результат**
Конкретный артефакт, который студент создаёт или получает на занятии: раздел design doc, диаграмма, расчёт, шаблон, код. Если занятие теоретическое без практического артефакта — писать "конспект лекции". Для занятий, где есть ДЗ или чекпоинт сразу после — результат должен согласовываться с тем, что сдаётся.

**Правила согласованности:**
- цели, содержание и результат одного занятия должны логически соответствовать друг другу — результат вытекает из целей, содержание объясняет, за счёт чего цели достигаются
- если после занятия есть чекпоинт или ДЗ — результат занятия и есть черновик/часть этого чекпоинта/ДЗ
- не дублировать формулировки между соседними занятиями модуля — если есть содержательное пересечение (как было с 3.1/3.2), заранее развести акценты
- сверяться с финальной программой курса и списком ДЗ (4 накопительных ДЗ и итоговый проект), чтобы результаты занятий стыковались с ближайшей сдачей или проектом

**Формат вывода:** по каждому занятию — заголовок (номер и название), затем 5 блоков: Смысл занятия / Цели занятия / Краткое содержание / Результат / Навык по занятию, как в примере ниже.

У каждого занятия есть шаблон который нужно заполнить

1. Название занятия

2. Смысл занятия

Один смысл занятия который отвечает на вопрос - "Для чего вам это уметь?"

3. Цель занятия

Обязательно три цели для каждого занятия

Ставится для студента.
Начинаем с глагола и перечисляем действия, которые смогут делать студенты после занятия и их смысл в профессиональной деятельности. Пример глаголов: использовать, применять, выбирать, анализировать, разработать и т.д.. (каждую цель начинаем с новой строчки, пишем со строчной буквы и не ставим никаких знаков в начале).

Например:

После занятия вы сможете (эту фразу писать не надо, она уже вшита в платформу)
создавать приложения для Web;
понимать возможности и ограничения пакетов при использовании веб-платформы.

ВАЖНОЕ: Еще пример для целей занятия

После занятия вы сможете:

понимать разницу между жизненным циклом модели и жизненным циклом системы
знать основные компоненты ML-системы и роль каждого: Storage, Feature Store, Training Pipeline, Model Registry, Serving, Monitoring
уметь пользоваться шаблоном design doc, который используется на протяжении курса

ВАЖНОЕ! Цель пишется с маленькой буквы и в конце у каждой цели ставится точка с запятой

4. Краткое содержание
(стек изученых технологий)

Расшифровываем тему подробнее и указываем технологии/понятия/процессы, которые рассмотрите на занятии.

Например: 

шаблоны проектирования: Singletone, Adapter, Bridge;
использование шаблонов проектирования Singletone.

ВАЖНОЕ! пример еще один:
разница ML Model Lifecycle vs ML System Lifecycle
компоненты ML-системы: Storage, Feature Store, Training Pipeline, Model Registry, Serving, Monitoring;
роли в команде MLSD;
шаблон design doc курса;
разбор архитектурных провалов на практике.

5. Результат

Указываем тот артефакт, который студент создаст в практической части занятия самостоятельно, либо же получит от вас. 

Это может быть документ, схема, заготовка кода, то, что можно скачать и использовать отельно от курса, как шаблон или пример. 

Если занятие теоретическое или артефакта нет, то в результате пишем - конспект лекции. 

6. Навык по занятию

Компетенция складывается из Знаний, Умений и Навыков (ЗУН). 

* Знания - понимание, сохранение в памяти и умение воспроизводить факты науки и вытекающие из них теоретические обобщения (правила, законы, выводы и т.д.)
* Навыки - действие, доведенное до автоматизма путем многократных повторений. Пробовал много раз, могу делать без помощи.
* Умения - способность делать что-либо, приобретённое знанием, опытом.

Для каждого урока нужно прописать, те ЗУНы, которые помогают приобрести компетенцию из предыдущего столбца.

Например,
Компетенция: работать с гитхабом 
Умение: создавать организации, репозитории"
