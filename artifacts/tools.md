# Инструменты и ПО для курса ML System Design

Курс — проектирование ML-системы, а не разработка и не обучение моделей. Код на занятиях и в ДЗ писать не нужно: примеры кода могут появляться для наглядности и не являются обязательными к запуску.

**Для обучения вам необходимо:**

- ОС: Windows 10/11, macOS 12+, Linux (Ubuntu 20.04+ или аналог) — достаточно обычного рабочего окружения, WSL2 не требуется
- Процессор: 4-ядерный CPU уровня Intel i5 / AMD Ryzen 5 / Apple Silicon и выше
- Оперативная память: от 8 ГБ (рекомендуется 16 ГБ, если одновременно открыты браузер с вебинаром, редактор и таблицы с расчётами)
- Видеокарта (GPU): не требуется — локально не запускаем обучение, инференс и Docker-образы с моделями
- Диск: SSD, минимум 5 ГБ свободного места (репозиторий design doc, диаграммы)
- Интернет: стабильное подключение от 10 Мбит/с (онлайн-занятия 90 минут, два раза в неделю, плюс git и облачные калькуляторы)

## Обязательное ПО

- браузер (Chrome, Edge, Firefox или Safari) — занятия проходят онлайн;
- доступ к учебной платформе OTUS и сервису вебинаров курса;
- Git 2.50+;
- аккаунт GitHub или GitLab: индивидуальный репозиторий сквозного проекта, доступ преподавателю на чтение; финальная версия — commit/tag;
- редактор Markdown с превью: VS Code или Cursor (рекомендуется). Google Docs допустим как черновик, но сдача — файл в git, иначе теряется история правок.

## Для разделов design doc

- диаграммы (архитектура, потоки, HITL): [Mermaid](https://mermaid.js.org/) в Markdown — предпочтительно, файл версионируется текстом. Альтернативы — [Miro](https://miro.com/), [draw.io](https://app.diagrams.net/), [Excalidraw](https://excalidraw.com/), PlantUML. Доска в Miro — личная: на курсе нет групповой работы и совместного ревью. В сдачу идёт экспорт PNG/SVG в репозиторий (`diagrams/`), а не ссылка на доску в чате;
- расчёты нагрузки, масштабирования и экономики (§4.3, §4.8, §6): Google Sheets, Excel или Numbers — формулы и допущения на отдельном листе; Jupyter допускается, но не обязателен;
- калькуляторы облачных цен для §6: [Yandex Cloud](https://yandex.cloud/ru/prices) или прайс выбранного провайдера в теме проекта;
- презентация к защите: Google Slides, PowerPoint и экспорт в pdf — ориентир 10 слайдов.

## Допустимо, но не обязательно

LLM-ассистенты для вычитки, таблиц и черновиков формулировок. Решения, числа и допущения должны быть вашими: на защите нужно воспроизвести цепочку рассуждений.
